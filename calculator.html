What a professional installation involves

Included as standard

Our standard back-to-back installation covers:

  • ✓ Indoor and outdoor units installed
  • ✓ Up to 4 metres of pipework and cabling
  • ✓ Up to 3 metres of exterior trunking
  • ✓ Condensate drainage
  • ✓ Electrical connection from the nearest suitable power point
  • ✓ Pressure and leak testing
  • ✓ Vacuuming
  • ✓ Commissioning and full system testing

Why the install matters

Performance, efficiency and reliability all come down to how the system goes in. A poor install invites drainage problems, refrigerant leaks, early breakdowns and a shorter working life.

Whoever does the work, it should include:

  • ✓ Correct positioning
  • ✓ Neat, properly insulated pipework
  • ✓ Proper drainage
  • ✓ Pressure and leak testing
  • ✓ Proper vacuuming
  • ✓ Electrical connection by a registered electrician
  • ✓ Commissioning and performance testing

Anything beyond a standard install — extra pipework or wiring, condensate pumps, brackets, roof mounting, scaffolding, concrete drilling, switchboard upgrades — is priced and agreed with you before any work starts.
